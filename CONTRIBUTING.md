# Contributing

Thanks for your interest in improving the GDP dashboard.

## Getting started

1. Fork or clone the repository.
2. Create a focused branch for your change.
3. Install dependencies with `pip install -r requirements.txt`.
4. Run the app locally with `streamlit run streamlit_app.py`.
5. Test the affected behavior before opening a pull request.

## Pull requests

Keep changes focused and describe what changed, why it changed, and how you verified it. Please avoid committing generated files, credentials, or local environment settings.
